# Webtextit

Marketing site for Webtextit, a software company that sells and builds apps, websites, custom software, ERP, CMS, and SaaS products.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Change before launch

- Contact email and site URL in `src/lib/site.ts`
- Product, service, and example copy in `src/lib/site.ts`
- The contact form opens the visitor’s email app addressed to that email. It does not send mail by itself.

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm run lint` — lint
